INTRODUCTION TO THE TRAINING

Build the Skills to Create with Generative AI

Generative Artificial Intelligence is rapidly transforming how people work, learn, research, develop software and solve complex problems.

However, there is a significant difference between using AI tools and understanding how to build applications powered by AI. This four-day intensive hands-on training is designed to bridge that gap.

Participants will progress from understanding the fundamentals of Generative AI and Large Language Models to building practical applications using Python, LLM APIs, RAG systems and AI agents.

The emphasis is strongly practical

30% Theory + 70% Hands-On Practical

You will not simply listen to presentations. You will learn concepts, write code, integrate AI models, work with documents and knowledge bases, build intelligent systems and develop a functional LLM-powered application.

WHAT IS THIS TRAINING ABOUT?

From Understanding AI to Building AI

This training introduces participants to the technologies behind modern AI applications and provides a structured pathway for moving from foundational concepts to practical implementation.

You will learn how to:

Understand

How Large Language Models and Generative AI work.

Prompt

How to communicate effectively with LLMs and obtain reliable outputs.

Program

How to integrate LLMs into Python applications.

Connect

How to connect LLMs to external information and documents.

Build

How to create RAG systems and AI assistants.

Develop

How to design and implement AI agents.

Deploy

How to transform your ideas into functional LLM-powered applications.

THE 4-DAY CURRICULUM

Your 4-Day Journey into LLM Application Development

DAY 1

LLM Fundamentals & Prompt Engineering

Start with the foundations of modern Generative AI and Large Language Models.

Topics include:

  • What are Large Language Models?
  • What is Generative AI?
  • How LLMs understand and generate language
  • Tokens and tokenization
  • Embeddings
  • Transformer architecture
  • How LLMs process information
  • Understanding hallucinations
  • Why LLMs hallucinate
  • Techniques for minimizing hallucinations
  • Prompt engineering fundamentals
  • Effective prompting techniques
  • Designing better prompts
  • Practical prompt-engineering exercises

Day 1 Outcome

By the end of Day 1, participants will have a solid conceptual understanding of LLMs and practical experience designing effective prompts.

DAY 2

Building with LLMs & Python

Move from understanding LLMs to actually building with them.

Topics include:

  • Introduction to LLM application development
  • Connecting LLMs to Python
  • Working with LLM APIs
  • API requests and responses
  • Managing prompts programmatically
  • Structured outputs
  • JSON mode
  • Processing model responses
  • Integrating LLMs into applications
  • Building a practical AI assistant
  • Hands-on Python development

Day 2 Outcome

Participants will understand how to connect LLMs to Python applications and will begin building a practical AI-powered assistant.

DAY 3

RAG & Knowledge Integration

Learn how to make AI applications work with external knowledge and documents.

Topics include:

  • What is Retrieval-Augmented Generation?
  • Why RAG is important
  • RAG architecture
  • Documents and knowledge bases
  • Document processing
  • Text chunking
  • Embeddings
  • Vector stores/databases
  • Semantic retrieval
  • Connecting LLMs to external knowledge
  • Building a RAG pipeline
  • Developing a document-based AI application
  • Practical RAG implementation

Day 3 Outcome

Participants will understand how to build systems that allow LLMs to retrieve and use information from external documents and knowledge sources.

DAY 4

AI Agents & Real-World LLM Applications

Take the next step from AI assistants to intelligent systems capable of performing tasks.

Topics include:

  • What are AI agents?
  • AI assistants vs AI agents
  • Agent architecture
  • Tools and tool use
  • Memory
  • Planning
  • Reasoning and task execution
  • Building autonomous AI workflows
  • Connecting agents to external tools
  • Developing an LLM-powered application
  • Application integration
  • Practical implementation
  • Capstone project

Day 4 Outcome

Participants will apply the knowledge gained throughout the training to develop and demonstrate a practical LLM-powered application.
